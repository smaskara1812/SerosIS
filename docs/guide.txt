How to run it (when you're ready)
1. Setup

pip install -r requirements.txt
cp .env.example .env
2. Pull Ollama models (one-time)

ollama pull llama3.2
ollama pull nomic-embed-text
3. Drop PDFs into data/manuals/, then ingest

python manage.py ingest_manuals
4. Start the server

python manage.py runserver
Then open http://localhost:8000 — the chat UI is ready.

When the manuals arrive, the only thing you need to do is drop them into data/manuals/ and run ingest_manuals. Everything else is wired up.
